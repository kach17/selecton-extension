Selecton Extension Test Page

Instructions:

  • Select text on this page to test tooltip functionality
  • Click in input fields to test text field tooltips
  • Check if borders appear/disappear based on settings
  • Verify arrow tip appears below tooltips

What to test:

  • ✅ Arrow tip should show by default (showTooltipArrow: true)
  • ✅ Button borders should show by default (showButtonBorders: true)
  • ✅ Copy button should show by default (showCopyButton: true)
  • ✅ Search button should show by default (showSearchButton: true)
  • ✅ Toggle settings in extension popup to see changes
  • ✅ Test individual button toggles work independently

How to test toggles:

  1. Right-click the Selecton extension icon → Options
  2. Toggle "Copy Button" off → select text → copy button should disappear
  3. Toggle "Search Button" off → select text → search button should disappear
  4. Toggle "Show Button Borders" off → borders should disappear
  5. Toggle "Show Tooltip Arrow" off → arrow should disappear
